a DOS PC.

Pocket Note Emulators is a Python program that boots to a DOS prompt, runs a BASIC interpreter, starts your DOS games and opens Windows 3.11. DOSBox Staging does the emulation. It runs from your own folders.

  • Windows 10 or 11
  • Python 3.7+
  • DOSBox Staging 0.83+
  • Windows installer
Get it What it does 


      

      
Click the screen and type. Try DIR, VER, COLOR GREEN or BASIC.

    

  


  

    
What it does

    

      

        

          
Power-on self test

          
A block-letter logo, a memory count from your real RAM, a keyboard check and a list of the drives on your computer, with the beep at the end.

        

        

          
A DOS prompt

          
DIR, CD, COPY, TYPE, REN, DEL, MD, RD and more, working on your real folders. PROMPT $N$G turns the prompt into C>.

        

        

          
BASIC

          
Type BASIC for numbered programs with LIST, RUN, SAVE and LOAD, loops, GOSUB, READ and DATA, arrays and SOUND.

        

        

          
Your games

          
Give each game its own folder. Type the folder name and DOSBox starts it. A game dropped in as a .ZIP unpacks itself.

        

        

          
Windows 3.11

          
WINSETUP installs it from your own disk images. WIN starts it, stretched to fill the screen.

        

        

          
A built-in checkup

          
DEBUG scans folders, DOSBox, games and Windows, tests its own commands, and saves a report you can send for help.

        

      

    

  


  

    
Windows 3.11

    

      
Windows 3.11 is not included. Use a copy you own, as floppy disk images (.IMG files). Windows for Workgroups 3.11 is listed on WinWorld: winworldpc.com/product/windows-3/wfw-311.

      
    
        
  1. Put the disk images in WIN311_INSTALL.
    2. 
        
  2. At the prompt, type WINSETUP. The emulator unpacks the images and starts Windows Setup in DOSBox.
    3. 
        
  3. In Setup, set Mouse to Microsoft, or IBM PS/2 and keep Display on VGA.
    4. 
        
  4. When the install ends, close DOSBox completely. Then type WIN.
    5. 
        
  5. Something off? WINCHECK lists missing files and drivers. WINCFG reopens Setup so you can change the mouse or display driver.
    6.

Help

    

      

        Windows starts but the mouse does nothing
        

          
Type WINCHECK. If it says MOUSE.DRV is missing, type WINCFG, set the mouse to Microsoft, or IBM PS/2, and answer D:\ when Setup asks for a disk. Close DOSBox and start WIN again.

        

      

      

        The Windows picture is garbled when the mouse moves
        

          
Use DOSBox Staging 0.83 or newer. Settings written for the old DOSBox 0.74 caused this. The first line of WINCHECK shows which DOSBox the script found.

        

      

      

        The picture looks too wide
        

          
Windows is stretched to fill the screen. For the normal 4:3 shape with black bars, set WIN311_FILL_SCREEN = False near the top of IBM.PY, in the IBM_DIRECTORY folder the installer made.

        

      

      

        The font does not look like an old PC
        

          
A script cannot change the font in Windows Terminal. Install a PC-style font, then choose it under Settings, Profiles, Defaults, Appearance, Font face. In the classic console window, put a .TTF file in the FONTS folder.

        

      

      

        The window closes at once, or says "py" is not recognized
        

          
Python is missing. Install Python 3.7 or newer from python.org, tick Add python.exe to PATH in its installer, and start the emulator again.

        

      

      

        Something else is wrong
        

          
Type DEBUG. It lists what is missing or broken and saves the same report to DEBUG_REPORT.TXT in IBM_DIRECTORY. Send that file when you ask for help.
